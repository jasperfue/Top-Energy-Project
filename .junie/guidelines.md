### Project Overview
This project is a Study application built with **Tanstack Start**.

### Tech Stack
- **Framework:** Tanstack Start
- **Storage:** Airtable (used to store results)
- **i18n:** Paraglide (Everything should be translatable)
  - Supported Languages: English (`en.json`) and German (`de.json`)
- **UI:** Tailwind CSS and Shadcn

### User Flow
The study follows a strictly defined flow for users:
1. `index` (Welcome/Start)
2. `affinity-for-technology`
3. `scenario`
4. `dashboard` OR `chat` (Variant dependent)
5. `questionnaire` (Steps 1 to 6)
6. `thanks` (Completion)
